# Sorteo Pro

Aplicativo web profesional para realizar sorteos aleatorios de nombres, ideal para concursos, rifas, eventos institucionales, colegios, fundaciones y empresas.

## Funcionalidades

- Ingreso de participantes, uno por línea.
- Selección de cantidad de ganadores.
- Sorteo aleatorio con animación.
- Los ganadores no vuelven a salir en sorteos posteriores.
- Limpieza de resultados sin reiniciar participantes.
- Reinicio total del sorteo.
- Contador de participantes disponibles y ganadores acumulados.
- Diseño moderno, responsive y escalable.
- Animación de celebración con confeti.

## Instalación

```bash
npm install
npm run dev
```

## Generar versión de producción

```bash
npm run build
npm run preview
```
